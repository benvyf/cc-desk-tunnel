# 引用与侧边追问

回答操作栏的“引用”把整条回答加入当前会话的输入框；选中回答中的一段文字，可选择“添加到对话”，右键菜单也提供同样操作。引用以独立胶囊显示，展开可查看原文、逐条移除。原有草稿保留，写下问题并发送后，回答继续保存在原会话。

“侧栏问”或选区菜单的“在侧边聊天中提问”会创建一个新的侧边会话标签。服务端冻结来源会话截至创建时已有的对话、工具记录和正在输出的片段作为背景；之后来源会话的新内容不会同步过去。侧会话使用独立的模型、审批、运行状态与草稿，停止侧会话不会停止主会话。关闭标签不删除会话，仍可从会话列表打开。

回答运行时，可在焦点所在会话内，500 毫秒内独立按两次 Esc 停止当前回答，或点击“停止运行”。单次 Esc、长按重复、输入法、菜单/引用浮层、审批和终端中的按键不会触发该快捷键。切换焦点、会话或运行后需要重新连按；停止会保留草稿并暂停该会话的待发送队列。在设置的“快捷键”页可查看说明，关闭快捷键总开关后仍可点击停止按钮。

引用和创建标签都不会发送消息或启动模型。侧会话的第一条明确发送的问题才会带上冻结背景，经原有远端 Claude Code 通道处理。背景中的旧任务和审批不会转移为待执行操作。本机侧栏预览的文件、网页、截图和浏览状态不会自动回传，也不会成为 Claude 可调用的接口；原有远端经 SSH 执行开发命令的能力保持原样。

每条消息最多包含 8 条引用，重复内容按来源去重。问题、引用编码和附件合计遵循原有 16,000 字符消息限制，超限需缩短问题或引用。上下文快照最多 256,000 字符，超限明确拒绝创建，不静默截断；它是服务端保留的对话记录快照，不是 Claude Code 内部上下文或隐藏状态的完整克隆。

主会话引用兼容已有节点。侧会话需要同时更新客户端和服务端；旧节点的侧栏入口禁用并提示更新，不会转为本机模型请求。未发送草稿和引用按会话保存；侧栏标签布局属于当前客户端，切换会话、重连和重启后可恢复。

功能参考 [dsh-harness-chat-control](https://github.com/1985899182/dsh-harness-chat-control)，沿用 CC SPACE 自有界面和远端会话实现，不依赖其 DSH 或 Better Sidebar 运行时。
