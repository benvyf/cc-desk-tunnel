# 上游引入改动复查

2026-11-03，香港时间。复查对象为 `dae1d25` 引入的安全依赖、额度与终端同步改动，以及本次修正。未部署到生产。

## 已修复

| 优先级 | 原问题 | 修正与验证 |
| --- | --- | --- |
| P1 | 原 PTY 重连后 ID 不变，旧屏幕的延迟渲染回调可能把旧字节确认为新输出，触发错误或关闭终端。 | 渲染确认按连接代次隔离；旧请求的迟到结果不改变新连接状态。浏览器回归验证旧回调不产生 ACK，新输出仍正常确认。 |
| P1 | 宽限期结束后，自动恢复调用普通打开命令，可能无提示新建 CLI。 | 恢复请求携带原终端 ID，服务端仅接回该实例；原进程已结束时显示结束提示，由用户明确新建。服务端和界面均有回归。 |
| P1 | 显式继续官方历史会产生另一个业务会话，按业务会话 ID 的旧锁无法阻止原聊天同时使用同一原生历史。 | 按原生历史 ID 检查聊天、终端、历史选择及原会话管理操作；验证原聊天发送和重命名均被拒绝，历史保持原样。 |
| P1 | 最后一次历史导入失败时，初始的“空历史”标记可能仍为真，进而误删未能读取的历史文件。 | 每次读取前将空状态置为未知，只在成功确认空历史后清理；故意让导入失败，验证文件仍保留。 |
| P2 | 终端暂停显示后，关闭标签被当成“已经结束”，客户端未发送关闭命令。 | 关闭标签仍调用控制句柄；服务端允许结束已分离、且调用方可访问的原实例。界面回归验证发送原 ID 的关闭命令。 |
| P2 | 状态 hook 保存完整提示词与工具输出，每次轮询重新读取大文件。 | hook 仅保存事件名、会话 ID 和通知类型；输入 1 MiB 工具输出时，文件只保留不足 200 字节的元数据。 |
| P2 | 账号页新开关使用未定义字号变量；恢复按钮撑满整行；断线标签显示“已结束”。 | 复用现有设置行与标准开关；恢复按钮使用现有小按钮和内边距；明确区分连接中断、启动失败和结束。 |
| P2 | 自定义 CLI 配置目录下的用户状态栏可能被默认目录的配置覆盖；旧独立历史的提示也容易被理解为已经合并聊天上下文。 | 从终端选定的配置目录保留用户状态栏；沿用独立历史时显示说明，通用输入提示只承诺关闭后恢复输入。 |
