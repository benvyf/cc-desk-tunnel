# Linux Build 24：30 GB 节点的精简镜像升级与默认清理

2026-11-16（香港时间）。已发布 Linux pilot **Build 24 / 0.3.10 / 协议 24**，源码 `d671527edb61470ecebbdd7b0ca370cf9d41a4ea`。仍为 Claude CLI 2.1.325 / SDK 0.3.286，支持 Fable 5.2；Windows Build 35 和管理中心运行文件不变。没有创建或执行 Ubuntu 安装任务。

## 实机故障及恢复

ubuntu-cc 更新 Build 23 时，Docker 29.9.1 在展开旧镜像后执行 npm ci 报 `ENOSPC` / errno -28，根分区使用率 100%。原镜像 Docker 报告大小为 7,492,242,490 字节，固定 2 GiB 构建余量没有计入 BuildKit 展开历史层的占用；这是 Build 23 空间预算遗漏。失败尚未进入切换，原容器 healthy，`/health` 正常。

用户执行 APT 缓存和 Docker 构建缓存回收，工具报告回收 7.886 GB，可用空间恢复到 5.1 GiB。容器、镜像、账号、会话和回退未删除。管理中心保留原失败任务，节点仍为 Build 21。用户明确选择保留约 30 GB 磁盘容量，并要求升级默认先清理，而非扩容。

## 修复

- 候选镜像从固定 Ubuntu 24.04 amd64 manifest `sha256:77eb101c607d6e3d4f5ad0c8a02c2136c689b98aba1f359e6502ba517e5c57ec` 重建，不再继承约 7 GB 的旧版本历史层。保留原声明的执行工具；Node、CLI 官方下载摘要和 SDK 依赖锁保持校验，现有数据和只读策略绑定沿用受管迁移流程。
- 在身份、来源和签名准入通过后，默认先执行有引用保护的缓存清理，再准备依赖、下载运行时和构建。无需 `--cleanup`。旧无引用 work 的 `program/`、`runtime/`、`node-extract/` 可回收；仍保护所有运行/停止容器、回退、已引用工作目录、策略和日志。
- npm 安装、运行依赖记录与应用目录权限收敛在同一构建层完成；不再对已经由官方安全解包并以 root 复制的运行时重复 chmod，避免再复制约 600 MB。切换普通构建用户时显式设置受管 Node PATH。
- 构建前检查 **5 GiB** 预算，已下载的运行时按实际字节抵扣剩余预算；原有冷备份/恢复空间检查保留。构建中每秒检查剩余空间，低于 512 MiB 或超时会终止构建命令，保留原服务并回收构建缓存。每 15 秒显示进度及日志位置；原始失败日志保留。
- 加入 Build 23 的精确描述符准入；不覆盖其已发布归档。默认空闲检查、最终受控断开、冷备份、健康检查、失败恢复和必要回退保护继续保留。138 个已发布 Web 资源按原字节复用。

## 验证及实际范围

在 Docker **29.5.3 / BuildKit** 下实际构建该配方。Docker 报告候选镜像大小 **581,768,326 字节**；该值不是整个构建过程的磁盘需求。采样实测初始空闲 5,610,954,752 字节、最低空闲 **902,242,304 字节**，最大额外占用 **4,708,712,448 字节**，包括暂存运行时 567,606,278 字节；不是在用户 Ubuntu 上安装的结果。

最终将预算常量从 4 GiB 提高到 5 GiB 后，Dockerfile 配方逐字不变。最终发行清单与预算脚本同步到独立验证镜像，全部清单、固定 Ubuntu 基础层、Node/CLI 的 root 所有者及不可组/全局写权限、真实 PTY 探测通过；按实测初始与已下载阶段空间值运行最终预算检查均通过。没有为预算常量变化重新执行未改动的 APT/npm 构建。

实际断网离线启动检查验证受管 supervisor 就绪、健康和 SIGTERM，哨兵确认未启动真实 CLI。Linux 迁移、低空间取消、默认清理、失败清理和回退引用保护 **35 项**通过。真实 CLI/SDK 读取模型目录包含 `claude-fable-5-2`；真实 PTY 的新消息审核、问答回复的既有范围及 SDK 不重复审核均通过。模型与审核交互仅为回环替身，无真实模型、JEV 或生产账号请求。

未发布候选的测试中曾发现 su 重置 PATH，以及重复运行时权限修改导致额外层占用，均在发行前修正。一次隔离构建在导出阶段触发 512 MiB 空间保护并自动清理，实测回收约 3.255 GB；此失败作为取消/清理证据保留，不冒称成功安装。

发布后，VPS 和开发电脑独立验证公开签名和完整包下载。实际运行公开签名迁移脚本自己的 HTTP 索引下载、验签、第二次归档下载和严格解包，确认目标 Build 24；节点、活动及空间状态使用替身，在构建/切换前主动停止。真实 systemd 续期成功，Linux revision **42**；线上实际 agent 在模拟 16/18/20/21/22/23 状态下选择新签名入口。三台已用节点和另外三台记录/既有任务、Windows pilot/stable 和管理中心均保持。

本次测试镜像和上下文已清理，构建缓存回收约 2.703 GB，原 5 个镜像及 7 个运行容器保持；VPS 可用空间恢复至 5,722,640,384 字节。不得删除 `/root/.cc-update-admin/linux-build24-preparation/source` 及精确续期引用制品。发布备份为 `/var/backups/cc-update-service/server24-publication-20261116T041813Z`。
