# CC SPACE 输入指令历史计划

**Goal:** 普通聊天输入框通过 ↑/↓ 复用先前提交的指令，并能恢复浏览历史前的草稿。

**Architecture:** 用户明确选择“仅当前会话”。直接投影当前会话已有用户消息和待发送队列，加一个输入框回溯游标；复用原会话/队列持久化，不另建本机指令库，不改变发送或协议。

**Tech Stack:** TypeScript、React、既有会话持久化、node:test、Playwright；不增加依赖。

## 交互合同

- 本轮处理主会话和侧会话的普通消息输入框。原生终端键盘仍交给 CLI。
- 普通 ↑ 在首个逻辑行、↓ 在最后逻辑行且无选区时，才进入历史；输入法候选、修饰键、斜杠菜单优先。
- 第一次 ↑ 保存草稿和光标位置，从最新一条开始；↓ 返回最新端恢复原草稿。调出的历史只填入正文，不自动发送。
- 编辑调出的文字后退出此次回溯，下一次 ↑ 保存该编辑草稿。切换会话先条件恢复原草稿，再清除回溯游标，不串草稿或覆盖其他视图的新编辑。
- 历史仅记录本次用户正文；发送失败不记，排队成功可记；连续相同指令不重复记录。附件/引用保持当前输入框状态，不复活旧附件或注入引用元数据。
- 只提供当前已加载消息中的最近 200 条可用正文，空白和连续重复项跳过；含附件/引用的历史只恢复正文，不自动挂回旧数据。持久化沿用现有会话，不从其他会话或项目取历史。
