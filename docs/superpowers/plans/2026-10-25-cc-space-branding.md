# CC SPACE branding implementation plan

**Goal:** Apply the approved S logo / uppercase CC SPACE layout across the desktop client and packaged application, retaining existing connections, drafts and upgrade compatibility.

**Architecture:** A small shared brand JSON supplies the display name and unchanged identity constants. A reusable Brand component uses the supplied light/dark SVG marks and real uppercase text. Preserve the packaged legacy profile before Electron's new display name can redirect it; preserve app ID, package identity, signed update product and legacy artifact filename contracts. New ordinary sessions default to Documents/CC SPACE and still recognize old Documents/CC Desk Tunnel sessions. System icons are generated directly from the provided SVGs, with dedicated small tray and macOS template assets. Repository URLs and server/deployment identifiers remain valid.

**Tech stack:** React, CSS theme tokens, Electron, electron-builder, Node.js and Playwright.
