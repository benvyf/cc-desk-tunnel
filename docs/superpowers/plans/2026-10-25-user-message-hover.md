# User message hover controls

**Goal:** Reveal the user's timestamp, copy and edit controls when the pointer enters the bubble, with enough time to move to its footer.

**Design:** Use local message state and one cancellable 800ms leave timer. Entering the bubble or visible footer reveals the controls and cancels the timer; leaving either starts it. Fade with the existing 120ms motion token, reserving footer layout space throughout. Keyboard focus reveals controls immediately and keeps them usable; devices without hover or with a coarse pointer keep controls visible. Unconfirmed delivery remains visible. Existing edit eligibility and assistant footer behavior stay intact. Reduced-motion users keep the reaction delay without a fade. A timer is preferred over CSS visibility because hidden visibility would also remove controls from keyboard navigation.
