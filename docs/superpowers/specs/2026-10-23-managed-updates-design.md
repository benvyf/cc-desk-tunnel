# 定制版更新隔离

用户已同意从 benvyf/cc-desk-tunnel 维护定制版，并先关闭在线更新，后续由管理员发布。

本次在 v0.3.6、协议 20 的固定源码上改动，不迁移生产、不改协议或版本解析、不实现内容审核。

- 生产服务不启动发布跟踪，即使旧环境仍指定官方或其他发布仓库，也不联网检查/下载/安装。客户端的服务端检查和安装命令均明确拒绝。
- 定制客户端不展示更新按钮、版本升级提醒或协议不匹配后的升级选项。版本不匹配仍提示联系管理员安装匹配定制版。
- Electron 的客户端安装、服务端升级 IPC 及发布说明请求均拒绝；备用发布下载默认关闭，不能回退官方。
- Docker 始终执行镜像内 /app，不再选用 /data/program 中先前下载的程序。不删除旧程序、用户数据、证书或配置。
- 项目和发布说明链接指向用户仓库。保留上游许可和历史说明。部署指南明确固定提交发布及逐台验证要求。

安全边界是禁止产品自带的更新通道；内容审核、终端能力及更完整的客户端权限控制属于后续阶段，不能宣称此改动已经防止所有源码替换。

验证覆盖：旧更新环境不生效、真实 WebSocket 更新命令拒绝、不出现下载公告、默认备用下载无网络请求、Electron 边界拒绝、界面无更新操作、Docker 忽略旧更新覆盖层。执行项目静态检查、类型检查、格式检查、适用自动测试及前端构建；Linux Docker 部署仍需 Linux 环境验证。
