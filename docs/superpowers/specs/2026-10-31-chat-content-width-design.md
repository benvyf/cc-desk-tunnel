# 聊天正文拖动调宽设计

用户已确认借鉴 Harness 的正文两侧拖动及轻量渐隐提示，并要求输入框联动、控制性能开销。此文落实该交互，不扩展模型、协议、预览接口或发布范围。

## 交互与布局

- 仅主聊天提供两侧调宽手柄。拖任一侧时保持居中，两侧对称伸缩；指针移动 1px 对应总宽度变化 2px。
- 正文、输入卡、上下文条、排队消息、运行摘要、连接说明和会话统计共用 `--chat-content-width`。默认偏好 820px；可调整下限 640px，上限为当前主聊天列宽减 120px。空间不足时 CSS 自然收缩，手柄隐藏；收窄不覆盖较宽的已保存偏好。
- 10px 命中条位于正文外 12px，提示线宽 2px、高 72px，中部 16px 实色、两端渐隐，采用已有 `--line-strong`。悬停、键盘聚焦、拖动时显示；拖动提示随指针 Y 更新。手柄只覆盖正文高度，不覆盖工具栏或输入框。
- 主正文采用对称水平留白，预留双侧滚动条槽保持正文和输入卡的中心一致。正文导航位于外侧，不和手柄争用点击。
- 左右方向键依手柄方向每次调整 10px；Home/End 到当前最小/最大值，双击恢复 820px 默认偏好。用 separator 语义提供当前值及范围。
- Escape、失焦、页面隐藏、指针取消、丢失捕获、卸载、切换主会话、列宽变化取消未完成拖动并恢复已保存值；按下即松开不保存。Escape 不触发停止回答。
- 偏好仅存浏览器/本机当前连接 profile 的 localStorage，读写异常时本窗口继续可用。不经过服务端、共享 IPC 或 Claude 工具。

## 性能及生命周期

独立控件通过 ResizeObserver 已有测量观察列宽；仅高度变化不修改宽度。指针位于手柄时，聊天区高度变化会按新位置校正提示线缓存，避免查找栏、连接提示等移动正文后提示线偏离鼠标；不在每次 pointermove 中读取几何。不扫描消息，不使用 MutationObserver。拖动保存最新指针并每个 requestAnimationFrame 最多写一次 CSS 变量和提示位置，不通过 React state 更新正文。只有实际提交才写一次 localStorage。捕获期间监听取消事件，结束后清理；卸载取消 RAF 和观察器。滚轮落在手柄上时转交原正文滚动区，Ctrl+滚轮保持浏览器原行为。

窗口级缓存保存存储不可用时的已提交偏好，跨会话和终端切换保留。一个不持有 DOM 的窗口级 storage 监听在控件卸载期间也失效缓存；活动控件另行监听以取消拖动和更新布局。开发热替换清理旧窗口监听。

手势和悬停位置有独立生命周期：结束或取消手势立即清空 drag 并取消旧 RAF，鼠标仍位于手柄时保留悬停位置供后续布局变化校正提示；pointerleave 再清理悬停坐标。悬停提示帧不修改已结束或取消的宽度。

## 验收

真实鼠标双侧对称调节、输入/队列/状态联动、默认与恢复、本地持久化、缩窗后复原、左右侧栏挤占、侧边聊天隔离、导航/选中文字/输入/流式跟随、取消与切会话、明暗主题与提示渐隐。以浏览器探针记录存储次数、DOM 更新和消息渲染、帧耗时；使用假服务，绝不调用真实模型。类型、构建及模型边界、相关回归通过后交付源码，不自动推送或发布安装包。

## 参考与选择

参考 Harness `ce7073d51254c26cd63b22a60835b8f948deb447` 的 ConversationWidthControls（MIT）：对称位移、指针捕获、RAF、共享 CSS 宽度轴。选择独立控件加共享 CSS 变量：逐帧更新全局偏好会重渲染全部聊天；引入面板布局库扩大改动范围。这两项均不采用。保留 CC SPACE 820px 默认偏好及主题变量，增加现有分隔条一致的键盘和取消操作。
