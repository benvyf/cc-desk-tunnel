# CC SPACE 本机预览工作区

## 目标与边界

补齐目录树、自动刷新、布局恢复、PDF/Office 预览、多窗格停靠。沿用现有预览侧栏及 CC SPACE 控件、颜色、排版。仅修改客户端；不增加模型工具、服务端协议、自动附件或预览内容回传。预览 IPC 仅受信任的客户端 UI 可调用，网页无 preload。目录和文档内容不进入模型消息。

文件树仅列出用户已选项目的本机目录，按展开加载，拒绝网络共享、越界符号链接及凭据目录。不扫描整盘。不提供文件写入功能。

静态文档不得产生外部请求。HTML 文件资源只访问自己的授权静态资源域名，阻止跨源请求、WebSocket、Worker、弹出窗口及下载。Markdown 禁止自动远程图片。本机网站仍须用户明确操作进入，不新增模型浏览或页面内容读取能力。

## 功能

1. 文件树：可折叠目录、刷新、选中文件、当前文件定位；加载/空/失败状态。目录按需列举，有界结果；不存在的目录保留错误提示。
2. 自动刷新：只监听展开目录及打开文件，合并变化事件，支持编辑器原子替换、删除及重建；销毁/重载释放监听。纯文档自动更新，HTML 自动更新显示静态资源，不能借刷新开放网络。
3. 布局恢复：按连接工作区、会话和 UI surface 隔离保存标签、活动标签、宽度、窗格与浮窗矩形、目录树开关。保存元数据而非正文。反序列化验证并限额。恢复网站及 HTML 标签先显示点击加载入口。
4. PDF：内置本地 PDF.js 渲染、页码、缩放、错误与加载状态，禁用脚本、外部链接自动访问。Office：随客户端打包的本机 LibreOffice Kit 转为 PDF，不使用在线转换或把文件上传模型。支持 doc/docx、ppt/pptx、xls/xlsx 及开放文档格式；转换不可用时显示错误与系统打开入口。转换使用独立临时 profile、禁用宏和链接更新、超时、限额、关闭清理。
5. 多窗格：在现有侧栏内部支持分栏、标签拖动重排/移动、浮动/停靠、浮窗移动及尺寸调整。合理限制窗格数量，不引入通用插件框架。每个窗格独立活动标签、原生视图 bounds；窄窗口采用堆叠。浮窗仍在当前应用内容范围内。

## 验收

新增文件树/监听/布局/转换与资源边界单元测试；现有预览回归。真实 Electron 验证 PDF/Office、目录树修改、重启恢复、两个同时可见的原生视图及停靠。模拟会话不调用真实模型；记录消息协议，确认没有预览正文/目录/网页传输。真实回环探针验证静态预览不能访问其他本机服务。浅深色、窄屏、字号及键盘交互截图检查。类型、构建、格式检查通过后交付分支与限制说明。
