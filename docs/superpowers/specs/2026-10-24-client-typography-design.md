# CC 客户端 Typography & Alignment 优化设计

日期：2026-10-24（香港时间）

## 目标与依据

将用户提供的六张排版参考图应用于 CC Desk Tunnel 客户端，改善中英文阅读、图标对齐、长字符串、动态数字与摘要展开。参考图中的 Claude 实现说明仅视为视觉目标，不作为已经核实的上游实现事实。

实际源码位于 `source`，origin 为 `https://github.com/benvyf/cc-desk-tunnel.git`。检查时 HEAD 为 `80e1dea`，工作区干净。本次范围是桌面工作台及共用 Web 工作台。

## 当前代码发现

- `apps/desktop/src/style.css` 已有 14px 基础正文、多个局部字号和 flex 居中；全局 SVG 为固定 18px，尚无明确的行内图标基线规则。
- `.message-content` 已使用 `overflow-wrap: anywhere`，但 `.empty-project` 仍使用 `word-break: break-all`；长路径和模型名称需统一检查所在 flex/grid 容器的收缩约束。
- 标题和正文尚未使用 `text-wrap: balance` / `pretty`。
- `tabular-nums` 已覆盖部分统计卡和用量表，尚未统一覆盖工具计时、运行状态、消息时间、搜索计数与上下文数字。
- `Conversation.tsx` 的 `Fold` 已按需挂载展开内容，审批时强制展开，搜索时展开；应复用。
- 思考摘要使用 `firstLine(item.text)`，且 `.thinking-preview` 单行省略。只修改 CSS 无法显示第二行原始内容。
- `RichText.tsx` 已 memo 化，Markdown 延迟加载；`RunStatus.tsx` 将定时刷新限制在小组件内。没有性能测量前不额外重构这些机制。

## 方案比较

1. **推荐：统一排版规则，配合少量组件调整。** 用 CSS 处理字体、换行、数字与对齐；复用现有 Fold 实现摘要交互。范围集中，能够覆盖参考图的五项要求。
2. **仅调整 CSS。** 风险最低，但无法修复思考摘要的数据截断，也无法提供普通提示的完整展开操作。
3. **重建视觉系统和对话渲染。** 影响范围大，当前参考图不足以支持全面改版，留待后续有独立需求时评估。

## 设计决策

### 字体层级与对齐

保留现有系统字体与主题。以 14px 正文、16px 组件标题、11–12px 辅助信息建立可复用字号和行高规则，页面大标题保留层级。避免把所有标题强行改为同一字号。

仅在文字流中的 SVG 使用随字号缩放的尺寸和 `vertical-align: -0.125em`，小号辅助文案可使用 `-0.075em`。图标按钮、工具栏、菜单和折叠箭头继续使用 flex 对齐。偏移值是起点，需在 Windows 中英文混排下目测验证，不承诺所有字体都能精确光学重合。

### 换行与长字符串

对允许多行的短标题启用 `text-wrap: balance`。在已完成回复和静态说明中使用 `text-wrap: pretty`。正在流式增长的正文保留普通换行，避免持续重新分配行长度。

可读正文、路径、模型名称和提示使用 `overflow-wrap: anywhere; word-break: normal`，并补齐受影响的 `min-width: 0` / `max-width`。代码块、终端和表格保留原有横向滚动，不按自然语言规则强制折断。

### 动态数字

为时间、token、额度、统计和计数器统一使用 `font-variant-numeric: tabular-nums`。只在必要的数字容器中设置不换行或最小宽度，不把整条长提示锁成单行。等宽数字减少同位数更新造成的位移；位数增长或单位变化仍可能改变宽度，验收时分别检查。

### 摘要与展开

- 会话侧栏标题保持 1 行省略，完整标题通过现有标题提示和会话进入路径访问，不在列表行内增加新按钮。
- 思考摘要最多显示 2 行，调整摘要提取以允许多行内容参与预览；点击现有折叠标题查看完整思考。保留搜索展开与审批强制展开行为。
- 超长的普通会话说明默认最多 3 行，提供独立“展开全文 / 收起”按钮与 `aria-expanded`，收起不丢失原文。
- 错误详情、审批内容和用户问题不截断，避免隐藏需要立即处理的信息。
- 仅在确实截断时显示展开操作；原生 details 控制与通知跳转按钮中不嵌套按钮。
- 展开优先复用现有按需渲染；如加入高度动画，必须支持 `prefers-reduced-motion`，避免每帧 JS 测量及消息更新时反复测高。

## 文件范围

主要为 `apps/desktop/src/style.css`、`Conversation.tsx`、`transcriptView.ts`；普通说明展开独立为 `RunNotice.tsx`，避免增大通用 `ui.tsx`。测试按实际行为变化调整 `apps/desktop/test`。行内 SVG 偏移不会改变 flex 图标的位置，无需修改各控件的 DOM。

## 验证与完成标准

1. TypeScript 检查、客户端构建和改动文件的格式检查通过。
2. 在隔离的本地模拟服务中验证，不使用真实 Claude 账号或真实原生终端。
3. 使用 1280px 桌面和 390px 窄屏截图检查中英文、长模型 ID、长路径和标题，页面无新增横向溢出。
4. 验证思考和普通说明展开/收起、键盘操作、搜索展开、审批始终可见；复制保留完整原文。
5. 同位数的动态数字更新保持等宽；核查 9→10 等位数增长不会挤压主要操作。
6. 流式回复继续显示；代码块、表格、终端、滚动跟随和长对话保持既有行为。对性能只报告实际测量结果，不从 CSS 改动直接推断速度提升。
7. 保存修改前后截图供检查，并运行相关现有 UI 回归测试；若未覆盖某个平台，明确记录限制。
