当前已发布的 Windows Build 27 使用协议 23，不能连接升级后的协议 24 服务。此次只发布 Linux 服务端及其配套 Web，不重新发布或更改 Windows pilot/stable。桌面完整使用需要另行打包发布协议 24 客户端。
