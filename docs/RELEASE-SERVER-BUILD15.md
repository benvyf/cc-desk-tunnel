# Linux Build 15：终端优化与 Build 14 配套升级入口

## 用户操作

1. 刷新 CC 管理中心，在 `ubuntu-cc`、`ubuntu-cc-02`、`ubuntu-cc-03` 对应的“服务端更新”中确认目标为 **Build 15 / 协议 24**。
2. 先结束正在运行或等待确认的任务，并关闭占用中的原生终端；普通空闲客户端不需逐个退出，升级流程会受控断开。
3. 新建并确认 Build 15 更新任务，逐台等待成功并核对节点显示 Build 15 后，再处理下一台。若界面提供需在 Ubuntu 执行的升级命令，刷新后复制对应节点的新命令；不要重用 Build 14 或更早任务的旧指令。
4. 空间不足、清理失败或节点忙碌时按错误日志处理，不降低空间预算、不删除回退资源、不强制停止工作。失败后的具体回退目录和命令由升级日志提供。

现有 host-updater agent 无需重装。该签名迁移仍只允许已审核的 01/02/03；未放宽 04/05/06 或其他节点授权。不要直接运行上游一键安装脚本替换本项目受管安装。
