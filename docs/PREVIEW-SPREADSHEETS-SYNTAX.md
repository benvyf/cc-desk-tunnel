# 表格预览与代码着色

侧栏现在直接预览 `.xls`、`.xlsx`、`.csv`、`.tsv`，Excel 不再默认转换为 PDF。表格显示只读单元格、Excel 格式化后的保存值、字母列头和数字行头；可用鼠标、左右方向键及 Home/End 切换工作表。水平和垂直滚动都留在表格区域，只渲染可见行。多行单元格以固定行高截取显示，悬停可读完整内容。

CSV/TSV 使用明确的逗号/制表符分隔，保留引号中的分隔符、换行、内部空行及 `00123` 等标识符。支持 UTF-8 和带 BOM 的 UTF-16。已有 HTML、Markdown、图片、PDF 与其余 Office 转 PDF 流程保持原有入口。

末尾真实存在的空行、引号包裹的空字段也保留，只忽略解析器未消耗任何字符而生成的末尾空记录；空行计入行数限制。Worker 完成或超时后均进入终态，迟返回的回调不能覆盖现有结果或错误提示。

表格只显示文件保存的数据，不执行公式、宏或单元格中的 HTML。公式没有缓存结果时显示公式文本。它是数据查看器，暂不还原图表、合并单元格、行列尺寸、隐藏行列或完整 Excel 排版；隐藏工作表不显示。ODS 继续走现有 PDF 转换。

解析在按需启动的 Worker 中运行，完成、超时、切换文件或关闭预览时终止。上限为 20 MiB 输入、64 MiB XLSX 解压声明体积、50 个工作表、10000 行、256 列、共 200000 个可见工作表单元格和 15 秒解析时间；超限会明确报错，不静默截断文件。

源码通过 highlight.js 与 CSS Custom Highlight API 着色，保留原来单一 Text 节点，行号定位、原文复制和原生选区继续使用准确的源码偏移。LF、CRLF 与 CR 换行保留原样。源码仍使用深色画布，颜色在应用的两种主题下保持可读。未知语言、超过 100000 字符的源码或不可用的着色器保持普通源码。多个预览窗格分别清理自己的着色范围。

## 验证

- Node 测试生成真实 XLS/XLSX 字节，检查中文、格式化金额、日期、公式缓存、工作表、隐藏表、CSV/TSV 引号/换行与编码、损坏输入和资源上限。
- UI 测试通过真实侧栏和 Web Worker 打开四种格式，覆盖键盘换表、5000 行混合多行单元格的滚动、受控 DOM 数量、窄屏两种主题和错误提示。
- 原有源码回归覆盖复制、选区、行列定位、自动换行、滚动恢复、跨窗格及接近 4 MiB 文件；新增测试验证着色、CRLF、颜色对比度和范围清理。
- `preview-parity-electron.test.mjs` 在提供 `CC_PREVIEW_PARITY_ELECTRON` 可执行文件路径时，构建真实预览资源，从 `file://` 在 Electron 沙箱、contextIsolation 与客户端 CSP 下验证 Worker，Node integration 关闭。

依赖固定为 SheetJS CE 0.20.3、Papa Parse 5.7.0、fflate 0.8.3 和 highlight.js 11.11.1，完整许可随客户端 `third-party` 目录分发。未复制 deepseek-harness 的表格或源码查看器实现。
