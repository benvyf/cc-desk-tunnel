# 本机预览工作区详细复核

审查基线：`947ec98`（`codex/preview-workspace`），本轮仅修正客户端侧栏及其验证。按 karpathy-guidelines 保持局部改动，未加入模型工具或新的聊天/服务端协议。

## 已复现并修复

| 问题 | 触发与影响 | 修正 |
|---|---|---|
| 独立窗口仍使用主文档查询 | 弹出终端关闭标签后焦点丢失，拖动标记残留，定位作用于错误窗口 | 查询、动画帧和滚动均使用控件所属文档 |
| 次级窗格最后一个标签关闭后失焦 | 窗格被删除，原 pane ID 已不存在 | 每个侧栏维护自己的 pane 元素映射，回退到同侧栏存活标签/入口 |
| 定位早于异步目录加载 | 当前文件的父目录已折叠，点击定位时目标行尚未创建 | 仅观察当前目录树，目标出现后滚动；成功、重复操作、切换和卸载时释放观察器 |
| 恢复的缺失文件无法自动恢复 | 首次读取/监听因文件不存在而失败，创建后没有变化订阅 | 仅文件监听允许有界缺失目标，监听已授权祖先，保持私有路径/范围检查 |
| 项目外手动选择文件不自动刷新 | 文件读取允许回退到文件父目录，但监听仍携带会话项目根 | 监听采用实际读取路径及有效范围；监听失败明确提示 |
| 退出发生在保存延迟内丢失布局 | 150ms 防抖未触发，文档销毁不会执行 React 卸载清理 | beforeunload/pagehide 同步保存最新元数据，保留平时防抖 |
| Office 排队后的目录校验过早 | 排队期间原目录改变，实际读取时仍依赖旧校验 | 真正读取前以及快照后重新校验原范围/私有目录，临时快照仍不进入模型协议 |
| 路径大小写比较不符合平台规则 | POSIX 路径 Case.md/case.md 被同时选中 | 复用项目现有 pathKey 比较规则，Windows 继续忽略大小写，POSIX 保留大小写 |

每项修复都有失败后通过的回归用例。Office 授权用例仅使用测试创建的临时目录与合成数据。

## 验证

- 桌面回归：298 项，244 通过、54 项按条件跳过、0 失败。
- 界面回归：24 项，包含弹出窗口/延迟定位、大小写路径和退出保存回归。
- Office 专项：10 项全部通过，覆盖 DOC/DOCX、XLS/XLSX、PPT/PPTX、外部图片请求拒绝、取消/限额、目录重新校验。
- 使用 Electron Builder 的真实生产依赖收集器核对所选引擎/Koffi；再从 ASAR 启动真实 Electron 验证转换，完整运行时可解析。
- 扩展的真实 Electron 全链路通过：缺失文件创建后的自动恢复、后续编辑、项目外文件刷新、多窗格/终端、PDF/Office、进程重启恢复、HTML 显式加载。模拟会话没有 message.send，不调用真实模型。
- 类型、构建、格式、仓库检查及差异空白检查通过。

验证环境为 Windows x64、Node 24 和现有 Electron 44。未生成或发布正式安装包；macOS/Linux 的原生运行仍需在对应平台实测。网络结论限于新增预览接口和已验证的请求策略，不把应用策略表述为现有执行通道的操作系统网络沙箱。
