# Claude 网页嵌入：初始试验版本

2026-10-25。分支 `codex/claude-web`，基于 Build 9（05918cdd）。仅账号本人使用自己的 Claude 账号。此版本用于验证远端画面和人手操作，尚未部署到 Ubuntu 或发布客户端。

## 当前可用范围

左上角原工作区 Logo 改为 **Chat / Coding**。Coding 的任务和草稿继续保留；Chat 使用打包的 noVNC 显示远端浏览器。切换时保留远端连接，隐藏时停止接受输入；画布失焦、切出窗口、隐藏或断线时清理键鼠及触摸拖动/长按状态。用户点击“连接远端网页”才发起画面连接；不自动访问 Claude 来探测登录、会话或额度。

浏览器、页面资源、登录 Cookie 和附件的官网请求均留在 Ubuntu。客户端只得到回环随机地址，不得到官网 URL、Cookie 或下载来源 URL；经当前 CC 服务的已验证 TLS 连接认证后传输画面与输入。连接失败会停止，不转为本机官网访问。Chat 下拒绝现有的本机外链 IPC；本地页面的既有 CSP、禁新窗口和禁导航规则继续生效。

这不表示整个既有 Coding 模块和 Windows 系统都不联网；也不保证远端实际网络永远使用同一个公网 IP，不代替账号使用权限或适用地区要求。

## 管理员配置与网络边界

服务默认不拨浏览器。管理员可在具备相应部署条件的试验节点配置：

```text
PROXY_BROWSER_ENDPOINT=ws://cc-claude-web-trial:6080/
```

该值由服务进程读取，不能由客户端选择。只允许 `ws`、根路径、无凭据/参数，主机限定为 `127.0.0.1`、`localhost`、`cc-claude-web`、`cc-claude-web-trial`。示例要求 CC 服务与浏览器在隔离的 Docker 网络内可达，且上游 WebSocket 服务实际监听该容器接口。现有试验的主机 `127.0.0.1:6090` 映射，**不意味着 CC 容器内的同名回环地址可访问它**。先核对容器监听、服务名、网络与 VNC 认证配置，再做管理员镜像部署；不要直接把 VNC、noVNC、CDP 端口暴露到公网。

普通用户无需在远端 Windows 打开浏览器或 SSH 窗口；Windows 若仍承载 Hyper-V，则仍需保持宿主运行。首次登录和失效后的登录在 Ubuntu 的真实浏览器中由管理员人工完成；管理员查看器只经受限管理链路使用。浏览器 profile 仅属于该账号本人，不能把已登录画面当共享账号服务。

现有 JEV 强制审核没有覆盖官网请求。因此凡配置 `moderation` 的节点，即使设置上游，也会返回 `moderation-required` 并拒绝建立网页通道。维护和关闭状态也拒绝连接。**不能为此移除审核配置。** 当前生产节点是否具备网页准入必须另行解决；本说明不授权绕过审核。

直接 TLS 的服务复用现有控制端口。使用 nginx 时，需要手动加入[示例](../deploy/nginx.conf.example)的 `/cc-browser/` WebSocket 代理段，并检查后重载。客户端无新公网入站端口。

新增客户端依赖修改了 lockfile；现有受管升级的兼容校验不能放宽。应由管理员准备并验证相应镜像和客户端包，保留当前生产构建用于回退。当前未执行安装、更新、发布或容器操作。

## 验证与上线前检查

离线自动测试覆盖：状态查询不拨上游、错误首帧/凭据、Origin、限流、单控制者、大二进制帧、错误证书不发送凭据、通道静默超时、并发打开/关闭取消、真实 Electron/noVNC 的像素与键鼠往返、模式切换保留画面与 Coding 草稿、按键释放和外链拒绝。Electron 测试使用真正的 main/preload/IPC、TLS CC 模拟服务和离线 RFB peer，不替换生产 IPC，不访问真实 Claude。

本地测试不能证明真实 Ubuntu 的出口或登录恢复已经通过。联调时由账号本人执行一次实际需要的页面操作，核对 Ubuntu Chrome 与节点实际出口，并检查本地客户端仅访问预期 CC 服务。需验证 IPv4/IPv6、远端浏览器重启后的 profile、断线与证书错误、过期登录维护提示；没有完成这些和中文/文件功能之前，不宣称完整需求已交付。

noVNC 固定 1.7.0，按连接时加载，字体与代码均本地打包，无 CDN。未修改其源码；版权、许可证及确切源码获取地址随包位于 `dist/third-party/noVNC/`。

本轮独立复核、缺陷修复和发布阻塞详见[复核报告](claude-web-review-2026-10-25.md)。测试通过仅作为离线实现验收；当前受管 Ubuntu 节点仍不能启用真实网页登录画面的客户端操作。
