## 已复现并修复

| 严重程度 | 原问题 | 修复与验证 |
| --- | --- | --- |
| P1 | 断线重连时管理中心暂时返回 502/网络错误，客户端永久停止重试；HTML 网关响应还暴露 JSON 解析错误。 | 区分临时错误与拒绝授权；错误类型显式跨 Electron IPC 传递。已建立的连接可退避重试并获取新票据，401/403 停止重试。先复现失败，再验证恢复与新票据使用。 |
| P2 | 已失效的记住登录一直保留，下次启动还尝试复用无效会话。 | 已认证请求收到 401 时清理对应内存/加密保存的会话；不让迟到的旧请求删除新登录。临时 502 保留原会话。回归覆盖两种情况。 |
| P2 | Nginx 后端把全部用户来源都识别成 127.0.0.1，单个来源错误登录会短暂阻断其他来源。 | 仅信任 loopback 代理送入、格式正确的 X-Real-IP；保留账号级限制。真实 HTTP 回归先复现跨 IP 误限流，再验证隔离与同账号跨 IP 限制。 |
| P2 | 多工作空间选择页不能直接回到邮箱表单；切换手动连接仍保留邮箱会话，旧错误信息也残留。 | 增加返回邮箱登录，退出邮箱授权并清理密码、重连和错误状态；页面回归验证。 |
| P2 | 邮箱连接仍展示依赖旧服务凭据的服务端升级操作，实际调用会失败。 | 此模式明确显示“邮箱连接请在管理中心升级服务端”，停止发出旧凭据请求。保留管理员现有升级命令。 |
| P2 | 关闭设备管理面板后，未保存的密码仍留在隐藏输入框。 | 关闭面板时重置用户表单和传统凭据输入；页面回归检查隐藏字段已清空。 |

同时将未知节点的验证请求限定为自有节点键，避免特殊对象属性名导致内部错误。
