## 行为与兼容

- 额度主动读取在服务端按登录身份合并，运行中每分钟最多一次；用户手动刷新例外。所有在线客户端都关闭主动读取时，只接收回复自带的额度。缓存命中不会伪装成新的 `quotaAttemptAt`，实际查询失败仍可由账号监控定位。
- 网络重连恢复同一个 PTY，并先恢复屏幕、键盘模式，再接收实时输出，不重发用户输入。无人连接时沿用 `PROXY_GRACE_SECONDS` 的宽限期（原生模式默认五分钟）；超时关闭进程。明确关闭终端、主动断开连接或服务重启不承诺保留进程。
- 尚未绑定过旧终端的会话，以聊天会话 ID 创建或继续原生历史，因此关闭终端后可以继续聊天。新版独立项目终端仍各用自己的会话；已有随机原生 ID 或“继续官方历史”的绑定不自动改写，保留原有独立上下文。
- 终端每轮结束后导入新增消息，保留时间并去重；不会把历史导入操作重新提交给模型或新消息审核。`/clear`、`/resume` 切换到其他原生历史后会显示说明，不把另一段历史混进原会话。
- 历史读取限定到该终端选定的 CLI 配置目录和项目，不扫描默认目录。用户已有 hooks、状态栏及只读管理策略保留；终端输入仍由既有官方 CLI 新消息审核 hook 决定是否放行。
- 终端运行时，账号页可单独查询额度；查询使用另一 CLI 状态读取，不抢占终端的原生会话，也不覆盖该会话的上下文和 Token 统计。

3. 先在临时数据中验证新基础镜像、协议 23、受管监督程序和审核 hook，再安排节点空闲时冷备份和切换。旧运行时必须返回人工基础镜像升级，不能修改签名或兼容性摘要强行安装程序包。
