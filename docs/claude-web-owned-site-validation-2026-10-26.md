# 自有网页远端出口验证

日期：2026-10-26 香港时间；下列服务端和抓包时间为 2026-10-25 UTC。基线 `fab9a78`。本轮没有改动生产客户端代码、访问 Claude、发布安装包或升级生产 CC。

## 结论

真实 Electron 使用现有 browser-view 和 browser-network-proxy 模块，经独立 Ubuntu 代理成功加载自有 HTTPS 页面。HTTPS、WSS、假上传、假附件下载、普通 worker、service worker、受控链接导航、断线阻断、显式重新打开后恢复均已实测。该结果支持继续集成验证，但不构成所有网络通路零泄漏、官网登录或生产 Chat 准入验收。

## 验证环境和证据

链路为本机 Electron → 本机认证 CONNECT → 固定证书指纹的 WSS → 管理 SSH 本地转发 → VPS 回环 → 专用受限 SSH 反向转发 → Ubuntu 独立 Node 代理 → 自有网站。生产 8443 入口及其 28787 目的没有变更。

网站仅临时开放 `api.ghostapi.org` 下的随机前缀。后端绑定 VPS 127.0.0.1:18790，20 分钟限时，固定路由，8 个并发连接、256 次请求、64 KiB 假上传、4 KiB 单帧 WebSocket 回显上限。nginx 去除 Cookie/Authorization 等请求头，不记录正文，只记录请求标识、来源、长度和摘要。安装及回滚经独立审查，五项 Python 测试通过。安装器的并发配置检查属于尽力检测，无法提供跨管理员的事务锁；回滚重载失败时停测试进程并保留现场，不能误报清理成功。

本机浏览器使用全新专用 profile，启用真实视图的沙箱和固定代理，禁用 QUIC、DNS 预取及 WebRTC 非代理 UDP。网站 TLS 使用正常 CA 验证，没有添加证书信任替身。Playwright 启动器还会增加自身测试 flags，因此仍需正式客户端入口单独验收。

管理员回传 eth0 抓包摘要：172.22.248.220 与 74.82.201.214:443 实际双向传输，17:06:23.260350 至 17:07:35.180442，共捕获 120 包、过滤器收到 123 包、内核丢包 0。抓包达到数量上限后停止，覆盖前两轮功能测试，未覆盖最后一轮完整恢复测试。第一轮标识 `run-1792947980278` 的服务端 marker、upload、ws 记录分别在 17:06:24.471461、17:06:24.751345、17:06:27.041347，均在抓包时间窗口内，来源为 115.132.85.120。抓包仅含连接摘要，不能从加密报文本身读出请求标识；来源公网 IP 相同也不能单独证明代理路径。

## 本机网络观察与限制

最终运行的 Chromium NetLog 中，所有 TCP_CONNECT_ATTEMPT 均为两个本机代理端口，没有网站 IP 的本机 TCP 直连记录。所有网站请求 URL 均在随机前缀内。

同时记录了五次面向 `[2001:4860:4860::8888]:443` 的 UDP 套接字连接，关联 HOST_RESOLVER_MANAGER_IPV6_REACHABILITY_CHECK；UDP_BYTES_SENT、UDP_BYTES_RECEIVED 和 DNS_TRANSACTION 事件均为 0。它与 Chromium 的 IPv6 本地路由探测相符，不能把 UDP_CONNECT 直接等同于已发送 UDP 数据，也不能仅凭 NetLog 保证系统层面没有数据包。系统 DNS、IPv6、WebRTC 等通路仍需进一步用本机抓包及正式入口交叉验收；本轮 Ubuntu 抓包只过滤 IPv4 测试站的 TCP443。

原始 NetLog 保持不变，分析器按 UTF-8 完整解码其 JSON，没有修饰或过滤事件内容。中途强制终止的一轮日志不完整，不作为完整验收证据。

下载测试使用程序指定的独立保存路径，未验证原生“另存为”对话框交互。导航检查证明现有视图跳转，没有额外断言所有窗口的数量。没有实测真实 Claude 附件、账号会话、账号区域隐藏或完整官网功能。
