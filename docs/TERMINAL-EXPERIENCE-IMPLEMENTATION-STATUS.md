历史首版采用有界本地 JSONL 元数据读取：只读已关联 ID 对应文件的前 256 KiB；长于 200 字符的 CLI 项目编码目录暂不猜测哈希格式，提示使用官方选择器。配置目录/可执行文件/设置路径变化会阻止继续；不读取 token 判断外部换号，用户须在继续前确认当前 CLI 环境与账号。未纳入 CC 管理的外部占用交由官方 CLI 自身处理，启动拒绝时保留错误，不强制接管。
