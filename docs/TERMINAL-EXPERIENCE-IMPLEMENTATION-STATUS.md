| 问题 | 修复与验证 |
| --- | --- |

| 选择文件或处理多张剪贴板图片时清空，迟到结果重新添加附件 | 清空及卸载使准备代次失效；迟到结果/错误及后续队列不能更新原草稿。浏览器覆盖文件选择和多图片准备。 |

## 第二次用户 review（2026-10-29，基于 cbe2504）

这次重点检查前一轮未覆盖的连接/设备切换时序、文件身份与错误溯源，未重构无关模块。发现并修复以下四类问题：

| 级别 | 问题及修复 | 验证 |
| --- | --- | --- |
| P2 | 文件预览弹窗打开期间，设备变化后迟到的 inspect 仍会启动本机读取，原“打开”操作也未失效。弹窗现在订阅连接/设备状态，隐藏失效内容和操作，在每次异步返回与打开操作前核对来源；换连接后不会自动读取新节点同名文件。 | 新增浏览器用例先复现失败，再验证设备切换期间零次后续本机读取、有效预览随重连清空。扩展节点文件用例验证过期回复被丢弃且不会重新请求。 |
| P2 | 旧终端订阅仅比较 sessionId，重连后同 ID 的新 opened/data 消息可以改变旧标签状态；旧输出链接也可能按新节点解析。消息与两种链接入口现在检查创建时的连接身份，已断开的终端不再接收新连接消息。 | 扩展断线用例，先复现旧标签被新消息变成“正在关闭”，修复后仍为断线状态且不出现新输出；点击旧文件链接仅提示连接变化，文件读取次数不增加。 |
| P2 | 本机“打开”复用了 Markdown 路径解析，将已经从 file URI 解码的 `%20` 再解码，可能与预览文件不同。现在直接传递已确认的同一个路径，仅给普通 CLI 路径解析行/列；file URI 的数字后缀保留为真实文件名。 | 浏览器断言 `report%2520.html` 的检查和打开均指向 `report%20.html`；节点 file URI `preview%3A2026` 保留为 `/tmp/preview:2026`。 |
| P2 | 终端启动的非领域异常被转换成通用提示，原异常没有记录，生产报错难以定位。现在服务端记录 requestId/sessionId/terminalId 和异常栈；日志调用不附带输入、CLI 参数或环境变量。 | 终端控制集成用例断言模拟启动失败有三项身份与原始异常，客户端仍收到稳定的 terminal_failed 错误码。 |
