# 代码导航与 PDF 文字选择实施记录

本轮从 `e07956fd99ec6f19f9ffe5f1547f4ad20b242e1f` 建立 `codex/preview-code-pdf-text`，落实用户确认的两项预览增强。实施清单见[计划](superpowers/plans/2026-10-31-preview-code-pdf-text.md)。当前为源码交付，不发布安装包或部署。

## 实际行为

- 文本、代码及 Markdown/HTML 源码显示行号，支持自动换行和正整数行跳转。行号不参与选区或复制，完整复制保留原文与末尾换行。
- 换行按连接、区域、工作区、会话和标签保存。行列链接通过现有文件链接解析进入侧栏；重复点击再次定位，超出有效行数裁到末行。一次性导航不写入持久布局，也不因移动标签或重启重放。
- Markdown 行定位切换到源码。恢复的 HTML 可以查看只读源码，但切回页面仍要求“加载此预览”，没有因定位执行页面。
- PDF 与 Office 转换结果复用当前页 PDF.js 文字层，支持鼠标选择、Ctrl+C 纯文本复制及 Unicode 规范化。页码、缩放、旋转、像素上限和视口变化使用同一有效布局尺寸。
- 无文字页提示可能是扫描件，不加入 OCR；文字提取失败保留成功画布。翻页、刷新、卸载取消旧任务并释放所属监听及选区，其他窗格和正文选区不受清理影响。

## 复用方式与边界

继续使用客户端已有 `pdfjs-dist@5.4.624` 的核心 TextLayer、字体布局、文字提取及 Unicode 规范化，不引入另一套 PDF 引擎或完整 viewer。TextLayerBuilder 内部绑定模块级 document/window，因此采用核心文字层加少量所属文档内的复制接线，适配 CC SPACE 的弹出窗口。文字层样式来自 PDF.js 的必要布局规则，已保留 Apache 2.0 来源声明及 NOTICE。

代码增强使用原来的代码块视觉变量、图标、CopyButton 与 Button；没有增加大型编辑器依赖、文件写入能力或新的语法解析器。行偏移只随正文改变计算一次，正文保持一个文本节点，按视口绘制行号。取消换行时按既有行高计算位置，换行时复用浏览器文本布局定位。

没有修改服务端、协议、Electron 运行时桥、依赖清单或锁文件。模型/API 请求仍从原有远端 SDK 发出，侧栏不向 Claude 暴露文件、DOM、文字层或截图接口。复制仅响应明确用户操作写入剪贴板，不自动创建引用、附件、侧边对话或消息。验证使用假服务与临时项目，不调用真实模型。

## 已复现并修正的细节

| 场景 | 原因与修正 |
| --- | --- |
| 已加载 Markdown 切源码并跳较远行 | 子组件布局阶段先定位，父阅读恢复后覆盖。改为父模式接线完成后执行一次可取消的动画帧导航，保留原模式阅读位置。 |
| 恢复的 HTML 标签查看源码 | 原确认门槛覆盖源码与页面。只将页面模式置于加载确认后，源码定位不会激活原生页面。 |
| HTML 条件分支首次挂载代码 | 父 ref 尚未赋值，ResizeObserver 收到空值。代码从自己所属的预览容器取得布局根。 |
| 空文件、空行及末尾换行 | 处理终止空行的显示与定位，不往复制原文加入额外字符。 |
| 超长代码远距离滚动 | 不必要的 inline code 层叠上下文造成浏览器原生绘制阻塞。CPU 记录显示 JS 很少、Range 调用约 1.5ms；取消该层叠上下文后，同一探针从秒级降至约 23ms，保留原代码块外观，以透明高亮覆盖目标行。 |
| 同帧链接定位后切换换行 | 待执行回调捕获旧布局。执行时使用最新导航回调，新的布局与定位计算一致。 |
| 浅色主题代码工具栏对比度 | 全局 ghost/hover 规则覆盖代码色。局部规则沿用 code-muted/code-text/code-hover，复制按钮复用原 code-actions，实测文字对比度不低于 4.5。 |
| 中文界面下 PDF 拉丁文字选框偏宽 | 界面语言影响系统 generic font，而 PDF.js 测量使用文档语言。为文字层传播 PDF 文档语言，未知时匹配引擎测量语言；像素对齐回归通过。 |
| 非默认 PDF 页面单位 | PageViewport 的画布布局包含 UserUnit，但文字层 CSS 比例最初只有 raw scale。用 0.5/2/3 单位及旋转/上限组合先复现比例错误，再将单位纳入同一 CSS 比例。 |
| 弹出窗口延迟加载 PDF | 文字层样式最初只注入主窗口。将同一组作用域样式随组件带入所属文档，保留主窗口测量画布隐藏规则。 |

## 性能与资源证据

环境为本机 Windows、Node 24、Edge，数据来自假服务，不代表模型响应耗时。以下是功能/压力回归中的本机样本，不宣传为跨机器性能保证。

| 工作负载 | 结果 |
| --- | --- |
| 约 1.6MiB、10500 行 | 打开约 198–203ms，远行跳转两帧约 7–13ms，换行后定位约 191–202ms；约 39 个行号节点、一个正文文本节点。 |
| 4,194,303 字节、25000 行 | 打开约 327–340ms，末行跳转约 45–46ms、换行后约 68–71ms；末尾视口约 7 个行号节点，完整原文与复制一致。 |
| 代码打开期间输入 37 字符 | 原组件保持，读取、文件监听及监听安装/清理计数不增加。 |
| 主侧会话各输出约 30 秒并输入 120 字符 | 预览关闭/打开各一组，输入事件到下一帧回调 p95 为 11.4/12.6ms；流式阶段无长任务、重新订阅或文件重读。该指标不是像素显示延迟或模型响应时间。 |
| PDF 页面与取消 | 只处理当前页；4096 像素画布上限与文字层布局一致，快速翻页及关闭后不保留旧文字和复制处理器。 |

行号节点上限为 256，读写与转换沿用现有限额。没有增加常驻轮询、目录/文件监听或 Office 转换请求。源码导航的帧任务在卸载时取消；已响应意图按会话/标签保存于内存，关闭标签或删除会话时清理。
