管理界面提供以下功能分区：

| 分区 | 功能 |
| --- | --- |
| 客户端更新 | 现有通道、候选、上传、发布、撤回和发布记录 |

| 审核记录 | 命中规则、审核结论、失败原因及关联节点/请求，供管理员查看 |

## 执行边界

管理员在 VPS 同一后台设置策略并查看记录；强制检查仍由 CC 服务端在内容交给 Claude 前执行。VPS 现有加密 TCP 中转本身不能读取正文，单独增加管理页面不构成拦截。

管理员令牌和生产更新签名私钥不下发普通客户端或 CC 节点；JEV 凭据由服务端保存，读取设置不返回完整密钥。节点审核调用的认证与请求/记录协议在实施设计中单独定义。

已有更新签名契约、发布数据和自动续期继续使用原机制。普通客户端拒绝行为沿用既定需求：操作结束并返回通用失败，不展示审核结论详情；管理员后台可溯源。对必须经过 JEV 的请求，超时或不可用不能默默放行。原生终端、文件/配置修改等绕过路径仍需评估，不以仅审核聊天发送事件宣称完整覆盖。
