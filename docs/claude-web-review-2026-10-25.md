# Claude 网页嵌入复核记录

2026-10-25。审查基线为 Build 9 `05918cdd`，初始嵌入提交为 `e4972b3`，修复位于 `codex/claude-web`。本轮按用户要求先复核，不部署、不发布、不操作真实 Claude。

## 发现及修复

| 级别 | 已复现的问题 | 修复与回归证据 |
| --- | --- | --- |
| P2 | 单地址占满 4 个未认证名额；静默认证不计失败，拒绝后还可拖延关闭 | 全局名额为 8，每地址仍为 4；5 秒认证到期计失败；拒绝后的 WebSocket 关闭期限为 1 秒。测试覆盖其他地址准入、静默限流、忽略关闭帧的 peer |
| P2 | 拒绝的半开 TCP 和未完成 HTTP 请求使本机桥关闭等待；关闭时新 accept 的 TCP 也可能遗漏 | 拒绝响应写完后销毁；跟踪所有本机 TCP；关闭开始即停止监听，迟到连接立即销毁，并发关闭复用同一 Promise。正常连接、半开和关闭竞态均有回归 |
| P2 | 窄窗口侧栏进入 Chat 后残留遮罩，挡住工具栏 | 进入 Chat 时收起窄窗口侧栏；500×800 回归验证可切回 Coding |
| P3 | 380×560 下工具栏换行，固定定位提示遮住按钮 | 提示放在工具栏之后的独立内容区；验证位置与横向溢出 |
| P2 | VNC 认证请求提示管理员，随后被通用断线提示覆盖 | 进入持久暂停状态，取消该次连接，保留管理员原因；不要求用户输入 VNC 密码 |
| P2 | 上游 WebSocket 正常响应心跳但不发送 RFB 握手，界面无限等待 | 独立 15 秒画面握手期限；到期暂停并提示管理员，无自动重试 |
| P2 | 拖拽时切出或隐藏窗口导致 mouseup 丢失，远端仍保持按下 | 在窗口失焦、文档隐藏或切模式前，经 noVNC 的正常 DOM 输入路径释放键鼠；同时释放捕获遮罩。离线 RFB 验证按钮掩码恢复为 0，界面按钮仍可点击 |
| P2 | 打包仅有通用 BSD 模板，缺少 DES 实现完整版权声明 | 加入源包 `core/crypto/des.js` 完整首注释，NOTICE 引用；重新 stageDesktop 与生成 ASAR 后提取核验内容一致 |

修复中再次复现了两个问题并闭环：TCP 快照之后、停止监听之前的 accept 竞态；直接在 canvas 派发 mouseup 虽释放远端按钮，却未释放 noVNC 捕获遮罩。最终实现分别提前停止监听、改走 window 的捕获代理。未使用 noVNC 私有字段，也未改其源文件。

## 尚未解除的上线阻塞

1. 受管 Docker 节点由 `enforceManagedDeployment` 强制配置 JEV。网页原始输入尚无同等审核路径，因此服务返回 `moderation-required`，拒绝建立显示通道。不能删审核配置来打通，也不能据此把真实已登录浏览器接入生产客户端。
2. 现有浏览器 trial 与 CC 服务缺共享私有网络。宿主 `127.0.0.1:6090` 不等于 CC 容器的回环地址；需检查私有监听、Docker 网络和服务别名。不向公网开放 VNC、noVNC 或 CDP。
3. 中文输入、本地附件传输、自动登录失效识别、官网账号菜单隐藏及只允许指定网页仍未交付。现有登录维护流程为用户手动暂停，管理员处理后手动重连。
4. 本轮不能验证真实 Ubuntu 的 IPv4/IPv6 出口、浏览器重启后的 profile、实际账号状态、资源压力或原生物理 Alt-Tab/托盘动作的全部路径。

下一步可进行 Ubuntu 只读网络和资源预检，并用独立合成画面服务验证受管门禁及网络。真实网页联调须先解决强制审核覆盖。离线代码通过不等于全功能交付，也不构成账号不会受限的保证。
