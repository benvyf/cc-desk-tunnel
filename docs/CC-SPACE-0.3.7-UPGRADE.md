## 发布边界

当前协议 20 的受管镜像固定了锁文件、`claude.ts` 与协议 schema 等兼容性摘要。0.3.7 修改了这些文件，需要新基础镜像，旧镜像通过普通程序更新应返回 `manual-image-upgrade`。不得修改或删除兼容性校验，不得修改旧 bootstrap profile、历史发布包或已签名索引来强行放行。

本次不更新 Claude CLI、SDK 依赖、审核策略或账号凭据。新镜像沿用审查后的官方 CLI、运行时和只读策略配置。直接运行通用 Dockerfile 会按 `install-linux.sh` 重新获取运行时，不能将其直接用于保留当前官方 CLI 的生产迁移。应以目标节点实际已审查镜像为基础，在隔离容器中验证新程序后，再安排镜像切换。

协议 20 和 21 的客户端与服务端不互通。Build 10 不应在试升级服务端准备好前激活到公共 pilot 渠道，否则现有设备会提示升级但旧镜像无法完成普通升级。
